# UI Color Scheme & Design System

Based on the interface provided, the following color palette defines the visual hierarchy, navigation, and content organization.

## 1. Primary Palette (Navigation & Branding)
These colors dominate the layout, specifically the sidebar and active states.

| Color Name | Approx. Hex | Visual Description | Usage |
| :--- | :--- | :--- | :--- |
| **Deep Cerulean** | `#007CA5` | Strong, saturated teal-blue | Sidebar background; Primary brand color. |
| **Bright Cyan** | `#00C2E0` | Vivid, high-contrast light blue | Active menu item background (Sidebar); Active pagination page (Footer). |
| **Action Pink** | `#FF476E` | Bright reddish-pink | Action buttons at the bottom of the sidebar (commas/quotes icons). |

## 2. Backgrounds & Surfaces
The structural colors used to create depth and separation.

| Color Name | Approx. Hex | Visual Description | Usage |
| :--- | :--- | :--- | :--- |
| **Pale Azure** | `#EBF5F9` | Very light, cool blue-grey | Main application background (behind the central white panel). |
| **Pure White** | `#FFFFFF` | Standard white | Main content card; Search input field; Sidebar icons. |
| **Table Stripe** | `#F9FAFB` | Off-white / transparent | Alternating row effects (subtle). |

## 3. Typography & Data
Colors used for text, table data, and readability.

| Color Name | Approx. Hex | Visual Description | Usage |
| :--- | :--- | :--- | :--- |
| **Charcoal** | `#2D3436` | Dark grey, near-black | Main headers ("Power units"); Row data (Unit names); Footer copyright. |
| **Slate Grey** | `#95A5A6` | Muted medium grey | Column headers ("STATE", "POWER", "TEDOM"); Inactive/Secondary text. |
| **Link Teal** | `#008B9B` | Medium teal | "Terminal" footer link text. |

## 4. UI Elements & States
Colors used for interactive controls and dividers.

| Color Name | Approx. Hex | Visual Description | Usage |
| :--- | :--- | :--- | :--- |
| **Input Border** | `#DAE1E7` | Light grey-blue | Search bar border; Checkbox borders. |
| **Active Check** | `#5D6D7E` | Dark blue-grey | Filled/Checked checkbox state. |
| **Divider Line** | `#E0E0E0` | Light grey (Dashed) | Horizontal separators between table rows. |
| **Pagination Blue** | `#D6EAF8` | Light blue tint | Hover states or background for pagination controls. |
